Keyref is a credential vault and CLI for developers and AI agents. Pass a reference like github-token, and Keyref supplies the stored value to the command when it runs.

Install Keyref

Available for macOS and Linux on arm64 and x86-64. The installer verifies the binary against the release’s SHA-256 checksums and places it in ~/.local/bin.

curl -fsSL https://keyref.sh/install.sh | bash

Add ~/.local/bin to your PATH if needed. Run keyref --version to check the installation.

Start with a local vault

Try it with a GitHub token and the gh CLI. Keyref passes the value to the child process and redacts matching values in captured output.

Read the CLI guide ↗

  1. Create a vault

    The vault stays on this machine. Its master key is stored in your OS keyring.

    keyref init

  2. Save a credential

    Paste the token and press Enter. Keyref hides your input. github-token is the reference you can share with an agent.

    keyref set github-token --source local

  3. Run a command with the ref

    Keyref injects the token as GH_TOKEN for this command.

    keyref exec --source local --env GH_TOKEN=github-token -- \
  gh api user --jq .login

Choose where credentials live

keyref list shows entries and their sources. If more than one vault can accept writes, use --source when saving.

Local vault

Encrypted storage on your machine, available offline.

GitHub account vault

Access your vault from multiple devices after GitHub sign-in. The server operator manages the encryption keys. Sign-in requires access to the configured server.
