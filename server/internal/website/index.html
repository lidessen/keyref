Install Keyref

Available for macOS and Linux on arm64 and x86-64.

Terminal install

curl -fsSL https://keyref.sh/install.sh | bash

The installer verifies the binary against the release’s SHA-256 checksum and places it in ~/.local/bin. Add that directory to PATH if needed, then run keyref --version.

Start with a local vault

Try it with a GitHub token and the gh CLI. Keyref redacts matching secret values in captured output.

CLI guide

  1. Create a vault

    The vault stays on this machine. Its master key is stored in your OS keyring.

    keyref init

  2. Save a credential

    Paste the token and press Enter. Keyref hides the input.

    keyref set github-token --vault local

  3. Run a command by reference

    Keyref reads github-token from the vault and sets GH_TOKEN for this command.

    keyref exec --vault local \
  --env GH_TOKEN=github-token -- \
  gh api user --jq .login

Choose where credentials live

keyref list shows entries and their vaults. Use --vault when saving and more than one vault is writable.
