# server

密文同步服务。**尚未实现。** 服务器不持有、也不能解开 VMK 或条目明文。官方托管和自托管是同一份程序。

设计见 [docs/design.md](../docs/design.md) 的「存储、部署与费用」和「服务端 API」两节。

- 一份 Go 二进制 `keyref-server`，内嵌 SQLite（纯 Go 驱动，`CGO_ENABLED=0`）。Docker 镜像里就是这个二进制。
- 官方托管把该镜像跑在一台固定月租的小机器上，并打开配额。自托管是 `docker run` 加上一个域名，或直接跑二进制。
- 只校验信封的形状、签名是否存在、设备是否有效、体积和配额是否超限。不要在服务器里实现解密。
- CLI 身份的设备不能写入或删除条目。
- 鉴权令牌只代表「这个设备可以来同步」，不是解密密钥。数据库里存令牌的哈希。
- 自托管默认不限额、不校验收据、不向官方服务器上报。官方托管必须打开配额；超额返回错误，不按量加钱。

建议的后续布局：

```
server/
├── go.mod
├── Dockerfile
└── cmd/
    └── keyref-server/
        └── main.go
```

费用（2026-10-20 的公开价，计算过程在设计文档里）：官方托管的固定成本大约 $18/月，含一台小机器、域名和 Apple Developer 年费。诚实用户的边际成本按 $0.01/月规划。免费档有硬配额；Plus 的推荐标价是 $6/月或 $48/年。自托管免费。
